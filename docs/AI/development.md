# Application Development using Agentic Coding Agents

## Application Development Steps

1. Create youre applicaiton architecture (Big picture)
2. Select the Coding Agents, AI Models.
3. Select the Application technology, (Development, Testing, CI/CD, Cloud Providers, Monitoring)
4. Build the AI Agents skill and coding style guides for the selected technology
5. Build RAG with Business skills
6. Implement OpenSpec / SpecKit in the development
7. Start Execute Iterative Development & Evaluation (Write -> Test -> Self-Correct via compiler logs -> Human Sign-off -> Deploy)
